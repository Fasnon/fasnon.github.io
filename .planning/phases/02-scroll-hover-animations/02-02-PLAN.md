**ProjectCard.vue — Replace existing hover classes on the root `<article>`**

Current root article classes include: `motion-safe:hover:-translate-y-2 hover:shadow-md transition-all duration-300`

Replace with the enhanced hover treatment. The full class list for the `<article>` should be:

```html
<article
  class="group overflow-hidden rounded-lg shadow-sm bg-white
    border border-transparent
    transition-[transform,box-shadow,border-color,background-color]
    duration-200 ease-out
    motion-safe:hover:-translate-y-2
    hover:shadow-card-hover
    hover:border-tame-green/40
    hover:bg-muted-peach/20
    max-w-[270px] sm:max-w-[290px] lg:max-w-[320px] mx-auto"
  :class="['flex', imageFirst ? 'flex-col' : 'flex-col-reverse']"
>
```

Key changes from current:
- `border border-transparent` added — invisible border at 1px width so border-color can transition smoothly (Pitfall 4 from research)
- `transition-all duration-300` replaced with `transition-[transform,box-shadow,border-color,background-color] duration-200 ease-out` — specific properties only, snappy 200ms timing (Pitfall 5), ease-out easing per user decision
- `hover:shadow-md` replaced with `hover:shadow-card-hover` — the custom earth-tone shadow from tailwind.config.js
- `hover:border-tame-green/40` added — border highlight using earth-tone palette on hover
- `hover:bg-muted-peach/20` added — subtle warm background tint shift on hover

Do NOT change the existing `motion-safe:hover:-translate-y-2` — it is already correctly wrapped in `motion-safe:`.

Do NOT change the image `motion-safe:group-hover:scale-105 transition-transform duration-500` — image zoom is a separate, intentionally slower animation.
